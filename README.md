# Amar Shoe Stores 👟

Official website for **Amar Shoe Stores**, located at Chitra Chowk Hotel, Hindustan International, Amravati, 444601, MH, India.

## 🌟 Features
- **Brand Aesthetic & Palette**: Light theme with Crimson Red, Royal Blue, Amber Gold, and Slate White accents.
- **Footwear Catalog**:
  - Boys Special Collection
  - Sneakers & Sports Shoes
  - Men's Formal Leather Oxfords & Loafers
  - Women's Designer Heels & Partywear
  - Royal Ethnic Zardozi Juttis & Mojaris
  - Kids Collection
- **Interactive Size Guide**: UK / IND / US / EU footwear size conversion chart & foot measurement guide.
- **Shopping Cart & Orders**:
  - Promo code discount system (`AMAR10`).
  - WhatsApp Direct Order checkout.
  - Direct Email Order inquiry sending to `rbasantwani999@gmail.com`.
- **Amravati Store Info**: Google Maps location navigation, store hours, contact details, and customer reviews.

## 🛠️ Tech Stack
- **Frontend**: React 18 + Vite 5 + Tailwind CSS + Lucide Icons
- **Deployment**: Static Bundle Ready (`dist/`)

## 🚀 Getting Started Locally

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build production bundle
npm run build
```
